## Suigin Koora Updates & "CVVX" Phonemizer

With the release of Suigin Koora (and OIL) on NeoDIVA, I took a break from UTAU. I think I'll start doing stuff again, I have just been incredibly busy recently.

I recorded a new JA CVVC voicebank for Suigin Koora. It has multiple pitches and voice colors. A demo is not yet available because I have only OTOed the first pitch, C3. Eventually, it will be more like this, with different voice colors having different pitches. (an `X` represents a subbank)

| Pitch | Base | Power | Whisper | NT |
|-------|------|-------|---------|----|
| C3    | X    | -     | X       | X  |
| G3    | X    | X     | -       | -  |
| C4    | -    | X     | -       | -  |

The NT version is a joke, as it was recorded with me plugging my nose to make it more nasally.

It will have the following extra phonemes:
* `l` (English `l`)
* `wr` (English `r`)
* `rr` (rolled r)
* `M` (M variant of `ん` (before `b`/`p`))
* `NG` (NG variant of `ん` (before `k`))
* `ff` (english `f` (Japanese `f` is more accurate to how it should be))
* `dj` (ぢ's consonant)
* `v Ex` (exhale)
* `v In` (inhale)
* `v Cm` (complex breath (out then in))
* `v Fr` (vocal fry)

Originally I was only planning to have it use a `presamp.ini` file to manage the extra phonemes, but it didn't work properly with the `JA CVVC & VCV Presamp` phonemizer. After converting it to romaji, I could get it to generally work with the `ZH CVVC Presamp` phonemizer, but some things didn't work. In the end, I decided ot commission [cadlaxa](https://cadlaxa.github.io/portfolio/) to make one for me. It uses a `YAML` dictionary. It is called the `JA CVVX` phonemizer. It is still in development, but eventually I will release it alongside my voicebanks (with some restrictions). So far it seems really good! Ideally, it'll act similar to DeepVocal's phonetic dictionary(or dictionaries..) which will make it much more customizable. When I get my hands on it, I'll make a blog post describing how it works and stuff, as well as making all of my currently-public voicebanks work with it. I'm not *certain* about the name, but I think it makes the most sense.

Also (yes there is more lol), Suigin Koora DeepVocal has been put on halt for a while. I am working on many other projects, and it isn't a very high priority for me. If I do it again (which I will, honestly I kinda don't like how "stiff" CVVC V2 sounds), I will use either v3 recordings or completely new ones.

## Kikyuune Aiko DeepVocal

Speaking of DeepVocal, I am making the official [Kikyuune Aiko](https://studiovo.xyz/voices/kikyuune-aiko/) JA DeepVocal voicebank! It's been a really fun project, and I am nearly finished with it (other than `t` phonemes, which haven't been recorded yet). Aiko is one of my favorite voicebanks ever, as she was the first UTAU voicebank I ever really used. I think DeepVocal sounds really cool and I'm so excited for it to release!
