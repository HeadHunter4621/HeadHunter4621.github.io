Installing DeepVocal voicebanks is a little harder than UTAU in my opinion, but it still isn't very hard to do. 

## Download Voicebank(s)

Downloading voicebanks for DeepVocal is about the same as UTAU. They're just distributed as `.zip` files. Due to DeepVocal not being as popular as UTAU though, it's a little hard to find voicebanks. Here are some that I've found. Also note that DeepVocal was originally only made for Chinese (with later functionality added for languages such as Japanese) and while there are voicebanks in other languages (such as English and Korean) they will probably be more complicated to use. Please read each voicebank's documentation to see how to use it!

* Japanese - [Tsukuyomi-Chan](https://shikuon.weebly.com/tsukuyomi-chan.html) (soft voice, good quality voicebank and easy to start with!)
* English & Japanese available - [Bunny](https://yinyangp.weebly.com/bunny-dv.html) (Neutral-tone voice. Haven't used it, but it's popular and sounds high-quality in the demos.)

Also, I recommend looking at [VocaDB's DeepVocal tag](https://vocadb.net/T/7191/deepvocal), especially the "top artists", to find other popular voicebanks.

If you're using English (and other-language) voicebanks, please make sure you understand DeepVocal's quirks before that. You need to use them more like UTAU (entering the phonemes directly), and the phonetic systems aren't really standardized. If you use an English voicebank, please read the voicebank's documentation thoroughly.

## Install Voicebanks

1. Unzip the downloaded `.zip` file to somewhere like `Downloads` (It doesn't really matter where, since it's going to get moved)
2. Move the voicebank folder (the one that contains the `SKC`, `SKI`, and `voice.sksd` files, sometimes others as well) into DeepVocal's `singers` folder (`C:\Program Files (x86)\DeepVocal\singers` if you used the default installation path). You might need to give permission to transfer the files, since `Program Files (x86)` is a protected folder in Windows, so just allow it to transfer all of the files.

That's it!
