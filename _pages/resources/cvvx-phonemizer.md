Phonemizer for my CVVX (and VCVX and CVX) voicebanks (CVVX is my modified system of CVVC, VCVX is my modified system/reclist for VCV, and CVX is a custom CV reclist (that I plan to write) with some specific aliases)

This is a custom phonemizer that I commissioned Cadlaxa to make.

If you want to make a voicebank with it, contact me (at my email, kouga-p@proton.me) for permission and instructions. **You may not develop a voicebank for it without permission.** It is not intended for use with normal JA CVVC/VCV/CV voicebanks.

## Installation instructions

Download and extract the `.zip` file

Put the `.dll` file in OpenUtau's Plugins folder (`C:\[User]\Documents\OpenUtau\Plugins\`, if installed with the installer)

Restart OpenUtau if it's open

From the phonemizer selector, select `JA: Japanese > [JA CVVX] Japanese CVVX Phonemizer (Contributed by Cadlaxa)`
