This is my highest-quality voicebank yet! I recommend using it with the [CVVX phonemizer](/resources/cvvx-info/), but it contains a `presamp.ini` file so that it will work with the Japanese presamp phonemizer in OpenUtau.

An update will come soon, which will add CV and VC aliases, but they are not added yet.

## Voicebank Info

* Reclist: Salem Wasteland VCV Lite reclist (with some modifications)
  * Romaji-aliased
  * `l` (English l) phoneme (only available as CVVC)
* Recording: E3 @ 120 BPM
